# CS303 Computer Networks - Syllabus

SYNTHETIC DATA: generated for development and testing, not an official AMYPO document.

## Course Information

- Course code: CS303
- Credits: 3
- Semester: 2025-26 ODD
- Prerequisites: CS202 Computer Organization
## Course Objectives

- Describe the layered architecture of computer networks.
- Explain routing, congestion control and reliable transport.
- Use common application-layer protocols and diagnostic tools.
## Unit 1: Network Models

Unit 1 of CS303 covers OSI and TCP/IP models, switching techniques, network topologies, performance metrics: bandwidth, latency, throughput and physical media.

## Unit 2: Data Link Layer

Unit 2 of CS303 covers framing, error detection with CRC, flow control and sliding window, Ethernet and MAC addressing and switches and VLANs.

## Unit 3: Network Layer

Unit 3 of CS303 covers IPv4 addressing and subnetting, IPv6, distance vector routing, link state routing and OSPF and NAT and ICMP.

## Unit 4: Transport Layer

Unit 4 of CS303 covers UDP, TCP connection management, TCP congestion control, flow control and quality of service.

## Unit 5: Application Layer

Unit 5 of CS303 covers DNS, HTTP and HTTPS, SMTP and email, socket programming and network security basics.

## Course Outcomes

- CO1: Explain the functions of each network layer.
- CO2: Design subnets for a given address block.
- CO3: Compare routing algorithms.
- CO4: Explain TCP congestion control.
- CO5: Build a simple client-server program using sockets.
## Assessment

CS303 is assessed out of 100 marks: 40 internal marks and 60 external marks. Internal marks consist of two Continuous Assessment Tests (CAT 1 and CAT 2) of 15 marks each and assignments worth 10 marks. The end-semester examination is conducted for 100 marks and scaled to 60.

## Textbook
