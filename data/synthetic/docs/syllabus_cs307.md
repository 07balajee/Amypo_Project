# CS307 Python Programming - Syllabus

SYNTHETIC DATA: generated for development and testing, not an official AMYPO document.

## Course Information

- Course code: CS307
- Credits: 3
- Semester: 2025-26 EVEN
- Prerequisites: CS101 Programming Fundamentals
## Course Objectives

- Write idiomatic Python programs using core data structures.
- Use modules, files and exceptions to build robust programs.
- Apply Python libraries for data processing and automation.
## Unit 1: Python Basics

Unit 1 of CS307 covers data types and variables, control flow, functions and arguments, string handling and list comprehensions.

## Unit 2: Data Structures

Unit 2 of CS307 covers lists and tuples, dictionaries and sets, iterators and generators, sorting with key functions and the collections module.

## Unit 3: Object-Oriented Python

Unit 3 of CS307 covers classes and objects, inheritance, dunder methods, dataclasses and abstract base classes.

## Unit 4: Files, Errors and Testing

Unit 4 of CS307 covers file handling, exceptions, context managers, unit testing with pytest and logging.

## Unit 5: Libraries for Data

Unit 5 of CS307 covers NumPy arrays, pandas DataFrames, matplotlib plotting, working with CSV and JSON and virtual environments and packaging.

## Course Outcomes

- CO1: Write Python programs using core data structures.
- CO2: Build reusable modules and classes.
- CO3: Handle files and exceptions correctly.
- CO4: Test programs with pytest.
- CO5: Analyse data with NumPy and pandas.
## Assessment

CS307 is assessed out of 100 marks: 40 internal marks and 60 external marks. Internal marks consist of two Continuous Assessment Tests (CAT 1 and CAT 2) of 15 marks each and assignments worth 10 marks. The end-semester examination is conducted for 100 marks and scaled to 60. Lab work carries 20 of the 40 internal marks, and the CAT weight is halved.
